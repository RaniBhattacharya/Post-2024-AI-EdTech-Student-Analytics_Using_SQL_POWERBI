# 📊 Impact of AI-Powered EdTech Adoption After 2024

### Student Performance & Engagement Analysis Using SQL and Power BI

---

## 📌 Project Overview

This project analyzes the **impact of AI-powered EdTech adoption after 2024** on **student performance, attendance, and engagement**. With the growing role of artificial intelligence in education, this analysis evaluates how AI-driven learning platforms influence academic outcomes across institutions.

Using **MySQL for data analysis** and **Power BI for visualization**, the project focuses on:

* GPA improvement before and after AI adoption
* Student attendance trends
* Engagement and platform usage patterns
* Platform-wise effectiveness of AI-enabled EdTech solutions

The project delivers **data-driven insights** through structured SQL queries and **interactive Power BI dashboards**.
